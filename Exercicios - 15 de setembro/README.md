# Exercício C13

Este repositório contém a resolução dos exercícios propostos na atividade `Lista de exercicios aula 15 de setembro`.

## Conteúdo

As questões estão resolvidas no notebook:

- `Exercicio_C13.ipynb`

O notebook contém as respostas, implementação dos sistemas de controle, simulações e gráficos referentes aos exercícios propostos.

## Como executar

Para executar o notebook, é necessário ter Python e as bibliotecas utilizadas instaladas.

Principais bibliotecas:

- NumPy
- Matplotlib
- Control

O notebook pode ser executado utilizando Jupyter Notebook, JupyterLab ou Google Colab.
